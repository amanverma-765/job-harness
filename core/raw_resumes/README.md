# Candidate Raw Resumes & Source Materials

Place past LaTeX, Typst, Markdown, or text-extracted resumes in this directory (`core/raw_resumes/`).

## Purpose
- Stores historical resume baseline drafts, transcripts, and credentials.
- Used by `/job:onboard` to extract past bullet points, work tenures, and education history into `core/profile.yaml`.
- Kept inside `core/` as permanent candidate source data rather than in temporary scratchpads.
