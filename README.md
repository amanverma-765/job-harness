# job-harness

Standalone Electron desktop harness for job seekers: automated ATS resume tailoring, Typst Resume-as-Code compilation, ATS pre-flight grading, and intelligent application tracking.

Built with:
- **TypeScript**
- **Electron + Vite + React**
- **Vercel AI SDK + Zod**
- **SQLite (`better-sqlite3` + `sqlite-vec`)**
- **Typst Resume-as-Code (RaC)**

## Research Suite

All ATS architecture, parser reverse-engineering, and resume specifications are preserved in [`research/`](./research/).
