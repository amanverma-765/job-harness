## About Apna Mart

Apna Mart makes groceries and everyday essentials available through neighbourhood stores and online ordering for local delivery. Its franchise network serves customers in tier-2 and tier-3 cities in India.

## About the Role

Ship real features to production with the Engineering team at a fast-paced grocery startup. With guidance from an engineer, take a scoped problem from requirements to rollout and work directly with Operations to see how the solution works in practice. The team uses AI coding agents daily and expects engineers to understand, verify, and own the code they ship.

## What You Will Do

- Build and test backend APIs and features in Python (Django, Flask, or FastAPI) or Node.js.
- Write SQL queries and work with PostgreSQL or MySQL.
- Talk to Operations to understand workflows such as investigating a stock discrepancy or tracking a delayed order. Confirm what needs to change and gather feedback after rollout.
- Fix bugs and investigate production issues with the team.
- Use AI coding agents to move faster, then review and test their output.
- Take small features from requirements to production with a mentor, including occasional frontend changes to internal tools.

## Must Have

- Working knowledge of one backend stack, either Python (Django, Flask, or FastAPI) or Node.js.
- SQL basics in PostgreSQL or MySQL, including joins and simple schema design.
- An understanding of how APIs, databases, and clients fit together, plus some experience building a simple web interface or connecting it to an API.
- Hands-on use of AI coding agents such as Claude Code or Cursor and the ability to explain the code they generate.
- Good data structures and problem-solving fundamentals.
- At least one project built independently and explainable in depth.
- Clear communication, ownership, and willingness to learn quickly. Ask specific questions, explain reasoning, and flag blockers early.

## Good to Have

- React or Nuxt (Vue), and familiarity with Redis.
- A previous internship or a shipped side project.

## Interview Process

1. Technical interview covering projects, fundamentals, and a walkthrough of something built.
2. Technical interview covering design basics and problem-solving approach.
3. Behavioural interview covering thinking, communication, and ownership.
