# Job Description: Software Engineering Intern - Server (Backend)

**Company:** Nudge (iSocial Sports Private Limited)  
**Department:** Technology / Core Platform Engineering  
**Role Title:** Software Engineering Intern - (Server / Backend)  
**Location:** Bangalore Corporate Office (Bengaluru, Karnataka, India)  
**Experience Level:** 0 - 1 yrs  
**Employment Type:** Full-Time Internship  
**Eligibility:** Final-year students or recent graduates (B.Tech / B.E. / MCA or equivalent)  

---

## The Opportunity

Nudge is building India’s ultimate commerce rewards platform. Users earn rewards by scanning shopping bills, linking accounts like Gmail or apps like Swiggy and Zepto, and playing games on our platform.

As a Server Intern, you will join our Core Platform Engineering team and ship real code to production. You will work on backend microservices alongside senior engineers, with a mentor guiding your work and reviewing your code.
This is not a shadowing internship. You will own small, well-scoped features and see them used by real users.

---

## What You’ll Achieve

### Ship Real Features
- Build and extend RESTful APIs for bill uploads, app integrations and in-app games.
- Take a scoped task from understanding the problem to a merged, deployed change.

### Learn How Production Backends Work
- Get hands-on with PostgreSQL, Redis, Docker and cloud deployments.
- Learn how real systems handle concurrency, caching, retries and data consistency.

### Build Good Engineering Habits
- Write unit and integration tests, and document what you build.
- Go through code reviews, and help debug issues using logs and metrics.

### Build Faster with AI
- Use AI coding tools (e.g., Claude Code, Cursor, GitHub Copilot) to write, test and debug code faster, while understanding and owning every line you ship.
- Use AI to explore unfamiliar codebases, draft tests and documentation, and prototype ideas quickly.

---

## What You’ll Bring

- Strong fundamentals in Data Structures, Algorithms and core CS concepts (OS, networking, databases).
- Comfort coding in at least one programming language such as Go, Java, Python, JavaScript/TypeScript or C++, and the ability to pick up new languages quickly.
- Basic understanding of how web APIs work (HTTP, REST, JSON) and of SQL databases.
- Familiarity with Git and a Linux/command-line environment.
- Projects that show you build things: college projects, hackathons, open source or personal backend projects (share GitHub links).
- Hands-on experience using AI tools in your own projects, and the judgement to review, test and correct what they generate.
- Curiosity, ownership and the drive to learn fast in a startup environment.

---

## Why You’ll Love Working Here

- **Production Impact:** Your code goes live and serves real users, not a sandbox.
- **Direct Mentorship:** Learn from senior engineers building distributed, high-concurrency systems.
- **Path to Full Time:** Strong interns may be offered a full-time Junior Software Engineer role.
- **Product-First Culture:** A fast-paced, high-ownership team where good work is noticed.
- **AI-First Workflow:** Modern AI coding tools are part of how we build, every day.
