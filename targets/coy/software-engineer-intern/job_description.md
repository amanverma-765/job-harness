## About the Job

### About Us
Coy is a dating platform that helps people find out if someone they like likes them back. The idea is simple: add someone you secretly have a crush on. If they add you back, it's a match. If they don't, nobody ever finds out. We believe Coy has the potential to make an interesting place for itself in the consumer internet space by combining curiosity, relationships, and a simple product experience.

### Role Overview
We are looking for a Software Development Engineer to join our core technology team and help build and scale Coy. You will work directly with the founding team, take ownership of product features and solve real engineering challenges.

### Key Responsibilities
- Build responsive web applications using React.js / Next.js.
- Develop scalable backend APIs using Node.js / Express.js.
- Build product features around onboarding, contact matching and mutual-match journeys.
- Integrate third-party services such as SMS, WhatsApp, email and payment gateways.
- Optimise application performance, security and scalability.

### Requirements
- Strong fundamentals in JavaScript and full-stack development.
- Experience with React.js, Next.js, Node.js and Express.js.
- Familiarity with SQL / NoSQL databases and REST APIs.
- Understanding of Git, GitHub and basic DevOps workflows.
- A builder mindset with experience in side projects, hackathons or products you've independently shipped.

### Why You Should Join Us
- Build a consumer internet product from an early stage.
- Work directly with the founding team and influence technology decisions.
- Take ownership of critical product features and see your work impact real users.
