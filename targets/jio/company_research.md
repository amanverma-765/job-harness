# Company Research: Jio Platforms Limited (Reliance Jio)

**Company:** Jio Platforms Limited / Reliance Jio Infocomm Ltd  
**Division / Area:** IT & Systems  
**Headquarters / Location:** Mumbai / Navi Mumbai (Reliance Corporate Park), Maharashtra, India  
**Work Arrangement:** On-site / Hybrid (Mumbai)  
**Industry:** Telecommunications, Cloud Services, Digital Platforms, and Enterprise IT Systems  
**Scale:** 450M+ telecom subscribers, handling billions of API calls, transactions, and event streams daily.  

## Company Overview & Platform Engineering
Jio Platforms Limited is India's largest digital services and telecommunications enterprise. The IT & Systems division is responsible for engineering, deploying, and maintaining the core operational support systems (OSS), business support systems (BSS), cloud services, microservices backends, and internal developer tooling that power Jio's digital ecosystem (MyJio, JioCinema, JioFiber, 5G network management, and enterprise digital operations).

Engineering within the IT & Systems group prioritizes clean architecture, robust software development lifecycles (SDLC), high code quality, automated testing, version control rigor, and resilient database performance under national-scale concurrency.

## Core Tech Stack
- **Primary Languages & Runtimes:** Python, Java, Kotlin, SQL, Bash, Go
- **Backend & APIs:** RESTful APIs, Spring Boot, FastAPI, Microservices, JSON, OpenAPI
- **Databases & Data Layer:** PostgreSQL, MySQL, Oracle, Redis, SQLite, distributed caching
- **Infrastructure & Systems:** Linux, Docker, Kubernetes, Git, CI/CD automation, Kafka
- **Testing & Quality Assurance:** Pytest, JUnit, integration testing suites, debugging and code review workflows

## Key Engineering Challenges & Hiring Gaps
1. **Resilient Data Processing & Database Query Rigor:** Designing normalized relational schemas, writing optimized SQL queries, and maintaining transactional integrity across high-volume customer and operational databases.
2. **Standardized SDLC & Test Automation:** Implementing robust unit testing, automated verification suites, and rigorous code reviews to prevent regressions in production applications.
3. **High-Concurrency API Design & Microservices:** Building clean, maintainable RESTful services with structured error handling, schema validation, and asynchronous worker queues.
4. **Reliable Tooling & Documentation:** Maintaining clear technical documentation, debugging production anomalies systematically, and collaborating across engineering squads via Git version control workflows.
