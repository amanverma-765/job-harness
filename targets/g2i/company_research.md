**Headcount:** ~250 employees and a global network of vetted engineers

**Core Mission:** Providing elite software engineers and domain experts to top AI labs and high-growth companies to build post-training data, reinforcement learning (RL) environments, evaluation harnesses, and synthetic training datasets for frontier models.

## Core Tech Stack & Methodologies
- **Core Languages:** Python, TypeScript, JavaScript, Go, Rust, SQL
- **AI & Evaluation Frameworks:** Pytest, Pydantic AI, OpenAI API, Anthropic API, Model Context Protocol (MCP), Hugging Face, ChromaDB, SQLite FTS5
- **RL & Training Infrastructure:** RL environments (RLHF / RLAIF / computer use), reward modeling harnesses, SWE-bench style sandboxing, Docker, Celery, Redis
- **Evaluation & Benchmarks:** Retrieval evals, paired statistical significance testing (McNemar, Wilcoxon), Recall@K, latency benchmarking, agentic tool-use trajectory generation
- **Data Engineering & Backend:** PostgreSQL, FastAPI, Celery, Redis, SQLAlchemy, Selectolax, Alembic

---

## Key Engineering Challenges & Talent Pool Focus Areas
1. **Verifiable Evaluation Harnesses (AI Evals):** Frontier AI labs require rigorous, reproducible test harnesses to evaluate model reasoning, coding capabilities, and retrieval precision. Creating paired statistical significance tests (e.g. McNemar tests) and deterministic automated test suites (90+ unit tests) prevents regression and hallucination.
2. **Reinforcement Learning Environments & Computer Use Sandboxes:** Designing reproducible environments where agents execute tools, interact with APIs, and receive deterministic reward signals without side effects or security leaks.
3. **Agentic Tool-Use Trajectories & Synthetic Training Data:** Generating high-signal, multi-turn tool calling traces (e.g. using Pydantic AI and MCP) with strict boundary isolation, input validation, and schema adherence to train frontier models.
