# Company Research: SAI Group Ltd

**Company:** SAI Group Ltd  
**Domain:** AI-Powered Enterprise Data Platforms and Conversational AI Systems  
**Headquarters:** Kolkata, West Bengal, India  
**Work Arrangement:** Remote / Hybrid (India)  
**Industry:** Information Technology, Enterprise Software and Artificial Intelligence  
**Engineering Culture:** Clean RESTful architecture, test-driven backend engineering, microservices, containerization, and robust API security standards.

## Company Overview & Platform
SAI Group Ltd is an enterprise technology provider building an AI-based conversational data platform. The platform enables users to connect enterprise databases (relational and NoSQL), upload documents and structured datasets, and interact with company knowledge through conversational AI interfaces and autonomous agentic workflows.

To support high-throughput natural language queries across distributed databases, the platform relies on performant Python backend APIs, asynchronous task orchestration, strict schema validation, and secure multi-tenant access control.

## Core Tech Stack
- **Backend Languages & Frameworks:** Python, FastAPI, Flask, Pydantic, SQLAlchemy
- **Databases & Caching:** PostgreSQL, MySQL, Redis, SQLite, NoSQL stores
- **API Standards & Protocols:** RESTful APIs, OpenAPI (Swagger), JSON Schema, JWT / OAuth2 authentication, RFC 9457 Problem Details
- **Asynchronous Task Processing:** Celery, Redis, background worker pipelines
- **Infrastructure & DevOps:** Docker, Linux, Nginx, Git/GitHub, CI/CD pipelines, AWS/Cloud environments
- **Testing & Quality Assurance:** Pytest, automated integration testing, unit test suites

## Key Engineering Challenges & Hiring Gaps
1. **High-Throughput RESTful API Architecture:** Scaling FastAPI microservices to handle concurrent conversational sessions and multi-tenant database queries with low latency.
2. **Robust Authentication & Security Hardening:** Enforcing granular JWT/OAuth2 token validation, rate limiting, and secure credential handling across external third-party API integrations.
3. **Database Query Optimization & Async Ingestion:** Optimizing complex SQL joins and batch indexing across PostgreSQL and relational datastores to prevent query bottlenecks during conversational search.
4. **Resilient Background Processing:** Implementing distributed task queues with Redis and Celery to handle long-running document extractions and external API webhooks without dropping requests.
